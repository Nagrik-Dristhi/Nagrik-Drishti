# Data sources & attribution

| Item | Source | Status |
|---|---|---|
| Base map (default) | OpenFreeMap vector tiles, © OpenMapTiles, data © OpenStreetMap contributors | in use, no key |
| Street / Satellite | Esri World Street Map / World Imagery / Boundaries & Places | in use, keyless; check Esri terms before public launch |
| OSM standard tiles | tile.openstreetmap.org | optional layer; OSM tile policy applies, blocked without a Referer |
| Place search | OpenStreetMap Nominatim (usage policy: light use, one request per user action) | in use |
| Province / district centres | Hand-entered APPROXIMATE centre points (`js/nepal-data.js`) | not boundaries |
| 753 local governments, wards | NOT included | needs official licensed dataset |
| Administrative boundaries | NOT included | needs official licensed dataset |
| Reports, statistics, departments, notifications | Simulated demo data generated in `demo-store.js` | DEMO ONLY |
